Optional custom sound for "paper" mode.

Place a file with exact name:
paper-crumpling.wav

Path:
./sounds/paper-crumpling.wav

If the file is missing, Binity automatically falls back to the standard Windows system sound.

The "trash" mode uses ./sounds/throwing-paper.wav and has the same fallback.
These files are bundled inside the packaged EXE. Source asset changes take
effect when running from source or after rebuilding the EXE.
